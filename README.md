# TBT Project - Dark Fantasy Turn-Based RPG

A classless dark fantasy RPG with ATB combat system, procedural exploration, and multiplayer support.

## Game Concept

See [Game_Concept_Summary.txt](./guides/Game_Concept_Summary.txt) for full design details.

**Key Features:**
- Turn-based ATB combat system
- Classless character progression
- Procedurally generated dungeons and overworld
- Multiplayer party exploration
- Dark fantasy aesthetic (2D pixel art)

## Recommended Tech Stack (All Free)

- **Engine**: Godot Engine (Standard) - GDScript
- **Backend**: Node.js + Express (or Python + FastAPI)
- **Database**: PostgreSQL (Supabase free tier)
- **2D Art**: Aseprite (pixel art)
- **Code Editor**: VS Code (free)
- **Version Control**: Git/GitHub (free)

## MVP Goals (First Version)

✅ User registration and login  
✅ Connect/disconnect functionality  
✅ Character creation  
✅ Spawn in square room  
✅ Character movement
